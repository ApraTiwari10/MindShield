# 🧠 AI Mental Health Risk Predictor

An AI-powered web application designed to assess potential mental health risk among students using behavioral and lifestyle indicators such as mood, sleep, stress, productivity, and daily habits.

The project focuses on **early risk identification and preventive support**, helping users understand potential warning signs and connect with appropriate resources.

## 🚀 Features

- 🧠 AI-based mental health risk prediction
- 📊 Risk-level classification based on user inputs
- 😴 Sleep, mood, stress, and productivity analysis
- 💡 Personalized preventive suggestions
- 📍 Location/GPS-based support resources
- 👨‍⚕️ Counselor/doctor assistance options
- 📹 Video consultation support
- 🎙️ Voice-input support
- 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

- Python
- Machine Learning
- HTML5
- CSS3
- JavaScript
- Pandas
- NumPy
- Scikit-learn

## 🔄 How It Works

1. User provides relevant behavioral and lifestyle information.
2. The system preprocesses the collected inputs.
3. The machine learning model analyzes the input patterns.
4. A potential risk level is generated.
5. The application provides preventive recommendations and relevant support options.

## 🎯 Objective

The goal of this project is to demonstrate how **Artificial Intelligence and Machine Learning can be applied to a real-world mental health challenge**, with an emphasis on early awareness, prevention, and accessible support.

## ⚠️ Disclaimer

This project is intended for **educational and awareness purposes only**. It is not a medical diagnostic tool and should not replace professional mental health evaluation or treatment.
